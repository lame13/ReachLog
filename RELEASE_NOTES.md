# ReachLog 1.2.1

Choose which account or email address to keep when reviewing duplicates.
Merging contacts preserves verification for the retained address and keeps
stakeholder roles separate from the primary contact.

Today and Telegram now respect a next step saved without a due date. Pipeline
totals include all currencies, and expected close dates display consistently
across time zones. Closing an opportunity through AI review records the close
date and cancels outstanding follow-ups.

Upgrade in place with the existing database and settings.

```sh
npm install --global reachlog@1.2.1
```
